#+title: firefox-cookies.el

=firefox-cookies.el= reads Firefox's =cookies.sqlite= and applies domain, path,
secure, expiry, and exact Container matching before returning cookies for an
absolute HTTP(S) URL.

There is no Chromium, Chrome, or Edge implementation.

* Configuration

Load the Firefox implementation once in your Emacs configuration and select a
profile explicitly:

#+begin_src emacs-lisp
(require 'firefox-cookies)

(setq firefox-cookies-profile-directory
      "~/.mozilla/firefox/xxxxxxxx.default-release/")

;; Only for a Firefox Multi-Account Container:
;; (setq firefox-cookies-origin-attributes "^userContextId=2")
#+end_src

Website packages can accept this function without depending on Firefox:

#+begin_src emacs-lisp
(setq zhihu-cookie-function #'firefox-cookies-get
      douban-cookie-function #'firefox-cookies-get)

(firefox-cookies-get "https://www.zhihu.com/")
;; => (("cookie-name" . "cookie-value") ...)
#+end_src

Any replacement cookie function only needs to accept one absolute HTTP(S) URL
and return the same alist shape.

* Security

Cookie values are credentials.  This package does not log them, persist a
second cookie jar, or send network requests.  Callers decide where cookies are
sent.  The live SQLite database is attached read-only; a private temporary
database/WAL snapshot is used only when direct reading fails and is deleted
immediately afterwards.
